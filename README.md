# Checkers
## Description
A simple checkers game made in python from scratch, using mainly pygame-ce.
This project was made to practice python fundamentals and so I can get back in this field.

## Features
Basically what each checkers game needs:
- Mouvement
- Queening
- Captures
- Multi-captures
- Play again

## Installation
- Clone the repository:
```
git clone https://github.com/Reeda13/Checkers.git
cd Checkers
```
- Install pygame:
```
python -m pip install pygame-ce
```
- Install numpy:
```
python -m pip install numpy
```
- Run the script:
```
python Checkers.py
```
